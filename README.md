# Stock-market

Stock Starter

A beginner-friendly project for learning a few stock market basics. The project uses plain HTML, CSS, and JavaScript in one file, so it does not need a framework or build tools.

## Features

- Short explanations of stock ownership, changing prices, and investing risk
- Fictional sample stock cards for practicing how to read a stock quote
- Share cost calculator
- Six-question quiz with scoring and a restart button
- Responsive layout for desktop and mobile screens

## Run the project

1. Keep `stock-starter.html` and this README in the same folder.
2. Open `stock-starter.html` in a web browser.
3. Edit the HTML file in a text editor to change the content, styles, or quiz questions.
